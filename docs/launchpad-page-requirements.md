## 1. 页面定位与用户故事

- **定位**：市场发现页 —— 发现、浏览代币并进入详情交易；本页**不自带搜索框与创建入口**，两者分别由顶栏全局搜索与顶栏「发布」菜单承担，避免同屏两个搜索/两个创建。
- **用户故事**
  - 作为用户，我可以在“进行中/已毕业”两个分区按热度/时间/市值/成交量浏览，快速判断哪些值得看。
  - 作为用户，我可以用本页的排序 / 时间窗切换浏览口径，用顶栏全局搜索按币名 / 代号 / 合约地址 / 创作者地址找到具体代币。
  - 作为投资者，我希望卡片把“曲线阶段/毕业池”状态、市值口径、发行者信息讲清楚，避免误读。

## 2. 主流程与信息架构

```
市场页（无页面级主标题、无自有搜索框、无自有创建按钮）
 ├─ 悬浮调试按钮：中英文切换（fixed 于页面最右侧；桌面右中、移动右下、不参与页面布局）
 ├─ 区块 A：已毕业（流动性已上池、永久锁定）
 ├─ 区块 B：进行中（发行曲线阶段）
 │    ├─ 排序：最近买入 / 最新 / 最早 / 市值 / 成交量
 │    └─ 时间窗：全部 / 24h / 7d
 └─ 点卡片 → 币详情

全局入口（不在本页）：
 ├─ 搜索：桌面顶栏搜索框 → `search-results.html`（默认「代币」页签）；移动端走首页 / 短剧页右上角搜索
 └─ 创建：桌面顶栏「发布」→ 发布中心 `publish-center.html`；移动端底部导航「+」面板 → 发布中心
```

## 3. 区块与控件

### 3.1 页面工具
| 控件 | 行为 |
|---|---|
| 中英文切换（调试） | 悬浮按钮，固定在页面最右侧（桌面垂直居中、移动端右下角底导上方），半透明虚线描边、hover 提亮；点击整页中英切换 |
| 语言切换 | 中/英整页切换并记忆 |
| 页面级标题行 | **不设**（首屏直接进入分区；`.px-shell` 顶部留白 28px） |
| 页面内搜索框 / 创建按钮 | **不提供**：搜索走顶栏全局搜索，创建走顶栏「发布」菜单（桌面）/ 底部「+」面板（移动） |

### 3.2 分区
- **进行中 Explore**：还在发行曲线上的币。卡片展示曲线进度、毕业阈值相关状态。
- **已毕业 Graduated**：已上池（Uniswap v4 池、流动性永久锁定）的币。

> 分区边界与链上 `phase` 一致：未毕业 / 已毕业。

### 3.3 排序（两区各自生效）
`最近买入`（默认） / `最新` / `最早` / `市值` / `成交量`
- 最近买入：按最近成交时间倒序
- 最新/最早：按发行时间倒序/正序
- 市值：按流通市值（MC）倒序
- 成交量：按成交量倒序

### 3.4 时间窗
`全部（默认） / 24h / 7d`
- 作用在 Explore 分区的“最近买入”语义上：仅统计最近 N 天有活动（或新发行）的币；选择窗口时列表只含该窗口内“有最新成交或新发行”的币。

### 3.5 关键词搜索与配对筛选
- 本页**不提供**关键词搜索框与筛选浮层：关键词搜索统一走全局搜索（见 §7），命中口径见 `docs/search-page-requirements.md`。
- 配对资产筛选（`全部` / `股票` / 各股票代币）随筛选浮层一并下线，本页不再提供该维度；后续如需回归，作为独立需求单独立项。

### 3.6 分页
- 已毕业：一页 6 条；进行中：一页 50 条（数值为产品默认，可调）
- 页码折叠：首/尾常显、当前页 ±1、间隔省略号；移动端展示简洁翻页。

## 4. 卡片规格与交互

### 4.1 卡片字段
> 卡片由共享模块 `launch-card.js`（`window.LaunchCard`）渲染，市场页与全局搜索结果页「代币」页签**同一份实现**，样式随模块注入。

| 字段 | 含义 |
|---|---|
| 大图（舞台） | 始终固定显示**币图**（无论是否关联视频）；hover 有视频的币在币图上播视频，离开即停 |
| 播放标（正中） | 仅关联了视频的币显示，居中圆形播放 icon；无视频不显示 |
| 名称 / $代号 | 币名与交易代号；右上徽标：毕业/OG/新/NEW |
| 计价资产 | 小字标注（如 · AAPL） |
| 市值 MC | 流通市值；有锁仓时并展示 FDV |
| 曲线进度 | 进行中币展示“已募/阈值”进度条与百分比 |
| 发行者地址 | 小字地址；**点击进入该地址的资产档案页** |
| 时间 | 最近买入/发行相对时间 |
| 警示徽标 | 发行者持仓过高（>20%）黄色警示；费共享币有收益共享标 |

### 4.2 卡片交互
| 动作 | 行为 |
|---|---|
| 点击卡片主体 | 进入币详情 |
| hover 大图（视频币，指针设备） | 在币图上播放 mute 视频，离开即停，回币图 |
| 点击发行者地址 | 打开该钱包档案（`assets.html?address=…`），从卡片移除“复制地址”主操作 |
| 触屏 | 不触发 hover 视频，仅显示静态币图 |

## 5. 业务规则

1. **状态口径**：是否毕业以链上 phase 为准；已毕业币不进入“进行中”区。
2. **市值口径**：默认展示**流通市值**（MC）；存在锁定/预留供应（lockedPct>0）时并列 FDV，避免混淆。
3. **成交量/时间窗**：24h/7d 口径与链上索引时段对齐；无对应成交数据的币在对应窗口被过滤或标“—”。
4. **发行者警示**：团队/发行者持仓占比 >20% 的币在卡片标黄警示（阈值为产品默认）。
5. **收益共享**：费共享币（费用归持有者）在卡片给标识。
6. **数据源**：列表数据来自链上索引；加载/失败/空态均有独立表现。

## 6. 异常与边界

| 场景 | 行为 |
|---|---|
| 无进行中 / 无已毕业币 | 分区空态 + 引导（去创建 / 调整排序与时间窗） |
| 排序 / 时间窗无结果 | 明确空态并建议换个排序或时间窗 |
| 本页无搜索入口 | 关键词搜索走顶栏全局搜索（`search-results.html`，默认「代币」页签） |
| 图片加载失败 | 回退到通用底图/代号占位 |
| 视频加载失败 | 回退币图，不出现破图 |
| 分页越界/快速翻页 | 页码收敛到合法区间 |
| 触屏 hover 限制 | 显示静态币图，无视频自动播放 |
| 语言切换 | 全量文案（含空态/徽标/aria）同步中英 |

## 7. 与创建页 / 详情页 / 搜索页的关系

- 创建入口在页面之外：桌面顶栏「发布」→ 发布中心（`publish-center.html`），在本页选「发币」+ 作品后发行；移动端底部导航「+」面板同入口；
- 创建成功的新币进入「进行中」并按默认排序出现；
- 点击卡片进入 coin-detail（曲线/池详情）；
- 点击发行者地址进入该钱包的资产档案页（公开只读视图）；
- 关键词搜索在全局搜索页完成，其「代币」页签复用的正是本页卡片（`launch-card.js`），命中口径见 `docs/search-page-requirements.md`。
