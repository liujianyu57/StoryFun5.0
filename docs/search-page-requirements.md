## 1. 页面定位与用户故事

- **定位**：全站统一的搜索结果页 —— 一个关键词同时检索**代币、短剧、视频、用户**四类对象，用页签分区呈现。
- **用户故事**
  - 作为用户，我在顶栏输入关键词回车后，希望**先看到代币结果**（本产品的核心资产），再按需切到内容或用户。
  - 作为用户，即使不输入关键词，我也希望这一页有内容可看（代币默认榜单）。
  - 作为投资者，我希望代币结果与市场页看到的是同一种卡片，字段口径一致（MC / 曲线进度 / 徽标 / 发行者）。

## 2. 主流程与信息架构

```
搜索结果页
 ├─ 搜索框（页面内，可改写关键词并即时重排结果；回车 / 输入即重排）
 ├─ 页签栏（sticky）：代币（默认） / 短剧 / 视频 / 用户   ← 每个页签带命中数量
 ├─ 结果区
 │    ├─ 代币：币卡片栅格（复用市场页卡片）+「加载更多」
 │    ├─ 短剧：短剧卡片画廊
 │    ├─ 视频：视频九宫格（点击进入作品模式播放器）
 │    └─ 用户：用户卡片列表（关注按钮）
 └─ 空态：未找到相关结果
```

- 入口：桌面顶栏搜索框、移动端首页 / 短剧页搜索入口、`search.html`（最近搜索）；URL 形如 `search-results.html?q=关键词`。
- 页签状态同步到 URL 的 `?tab=`；**默认页签为「代币」，默认值不写入 URL**（`?tab=token` 会被规范化为无该参数）。

## 3. 页签规格

| 顺序 | 页签 | 默认 | 结果形态 | 命中字段 |
|---|---|---|---|---|
| 1 | 代币 | ✅ 是 | 市场页同款币卡片栅格（`launch-card.js`） | 见 §4.2 |
| 2 | 短剧 | 否 | 短剧卡片画廊 | 标题 / 分类 / 简介 |
| 3 | 视频 | 否 | 视频九宫格 | 标题 / 作者 / 简介 |
| 4 | 用户 | 否 | 用户卡片列表 | 作者名 |

- 每个页签右侧显示当前关键词下的**命中数量**（数量为 0 时显示 0，不做隐藏）。
- 切换页签不改变关键词，也不新增浏览历史（`history.replaceState`）。
- 传递 `?tab=drama|video|user` 时直接落在对应页签；`?tab=token` 等价于默认。

## 4. 「代币」页签规格

### 4.1 数据源
- 复用发射台引擎 `launch-coin.js`（`window.Launch.coins`）：与市场页、币详情页同一份数据，不另建索引。
- 包含**已毕业**与**进行中**两类代币，卡片自身以徽标区分（已毕业显示 `Graduated`）。

### 4.2 命中口径
按以下字段做**不区分大小写**的子串匹配（字段之间取并集）：
1. 币名 `name`
2. 代号 `symbol`（支持 `$TICKER` 写法，查询串以 `$` 开头时自动忽略该前缀）
3. 计价资产 `pair`（如 `AAPL`）
4. 合约地址 `Launch.coinContract(id)`
5. 创作者地址 `creatorAddr`
6. 币 id `id`

**不命中**：`buyerAddr`（最近买入地址）。理由：全局搜索是"找到某个币"的入口，不该因为「某人最近买过」而把币搜出来；买入者检索属于地址档案页的能力。

### 4.3 排序与默认榜单
- 一律按**流通市值（MC）降序**排列（有关键词、无关键词同口径）。
- **无关键词**：直接展示默认榜单（全部代币按 MC 降序），首批 24 条 —— 保证默认页签打开即有内容。
- 结果区顶部一行摘要：有关键词显示「「关键词」共 N 个代币」，无关键词显示「全部代币 N 个 · 按市值排序」。

### 4.4 分页
- 首批 24 条，底部「加载更多（剩余 N）」按钮，每次追加 24 条；到底后按钮消失。
- 关键词变化（输入 / 清空 / 回车）时分页回到第一批。
- 页签切走再切回不重置已加载条数（同一关键词下保留浏览进度）。

### 4.5 卡片与跳转
- 卡片由共享模块 `launch-card.js` 渲染，与市场页**同一份实现**：币图恒定显示、仅关联视频的币在币图正中显示播放标、hover（精确指针设备）播放 mute 视频、毕业/OG/警示/收益共享徽标、MC、曲线进度、发行者地址与时间。
- 点击卡片主体 → `coin-detail.html?id=<币 id>`；
- 点击卡片内发行者地址 → `assets.html?address=<地址>`（不触发卡片跳转）。

## 5. 业务规则与状态口径

1. **统一入口**：全站关键词搜索只有这一页；市场页不再提供自有搜索框（避免同屏两个搜索）。
2. **口径一致**：代币结果的字段与排序口径必须与市场页一致（同一引擎、同一卡片模块）。
3. **数量徽标**：页签数量为当前关键词下的命中数，随输入实时更新。
4. **URL 契约**：`?q=` 关键词、`?tab=` 页签；两者都可分享/刷新还原。
5. **内容类结果**：短剧 / 视频 / 用户的检索与排序沿用各自既有规则，不在本页另立口径。

## 6. 异常与边界

| 场景 | 行为 |
|---|---|
| 无关键词 | 「代币」页签展示默认榜单；其余页签展示该类全量结果 |
| 代币无命中 | 空态「未找到 "关键词" 的相关代币」 |
| 引擎未加载 / 数据为空 | 代币页签空态「暂无代币」，不报错、不影响其他页签 |
| 币图加载失败 | 回退通用底图 + 代号占位 |
| 视频加载失败 | 回退币图，不出现破图 |
| 触屏设备 | 不触发 hover 视频，卡片仅显示静态币图与播放标 |
| 分页到底 | 「加载更多」按钮消失，不出现空按钮 |
| `?tab=` 非法值 | 回落到默认「代币」 |

## 7. 与市场页 / 详情页 / 资产页的关系

- **市场页**（`launchpad.html`）：不再提供搜索框与创建按钮；其卡片实现即本页「代币」页签所用模块（`launch-card.js`），两处改动必须同时生效。
- **币详情页**（`coin-detail.html`）：代币结果的唯一落地页（`?id=`）。
- **资产页**（`assets.html`）：卡片内发行者地址的落地页（`?address=`）。
- **地址档案**：合约地址与创作者地址可作为检索词，命中后仍落在币详情页，不做独立地址搜索结果页。
