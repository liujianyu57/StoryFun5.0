# 我的资产「assets」· 产品需求说明

> 按真实产品语义撰写；不含演示数值。
> 页面：`assets.html`（我的资产 = Portfolio 总览 + 持仓/历史/流水/发射）
> 阅读建议：本页是「账户级」页面：先读第 1 节（登录 / 访客两态），再看第 2 节结构总览，各页签细节按 §6–§9。
> 未定义细节处理原则：以 pons 实测为准；观测不到的取最简默认，不再展开评审。

---

## 0. 页面定位与用户故事

- **定位**：登录用户的资产中枢：看总市值与 PnL 曲线、管持仓（含分享）、领持有人分红与 Creator fees、回看历史与流水、管理自己发射的币。
- **用户故事**
  - 作为用户，我打开就能看到 Portfolio、一段时间 PnL 走势，以及可一键领取的 Holder dividends / Creator fees。
  - 作为持仓者，我想按行查看 Entry mcap / Current mcap / Value / PnL，并把它做成分享卡发给别人。
  - 作为发射者，我想看自己发射的币与未领取的 Creator fees。
  - 作为访客，我应能通过地址只读浏览某账户的资产（演示数据），但不能领取任何收益。

---

## 1. 访问态与权限

| 状态 | 行为 |
|---|---|
| 未登录 | 隐藏 hero / Portfolio / 横幅；内容区显示“登录后查看资产”卡（`needLogin`），点击弹登录引导；`auth-ready` 后自动重渲染 |
| 已登录（本人） | 完整功能：总览、四个页签、两个领取横幅、持仓分享 |
| 访客 `assets.html?address=0x{40}` | 顶部出现“访客视图 · 演示数据 · 返回我的资产”条；地址展示为所查地址（头像取地址首字符）；数据为同一演示档案；**领取一律禁用**（横幅隐藏 / 按钮 toast 提示） |

> 实现说明：`address` 校验 `0x` + 40 位 hex；访客与本人共用同一份演示数据源，仅身份展示与领取能力不同。

## 2. 页面结构（自上而下）

```

2 钱包资产面板（桌面居中面板、移动全屏抽屉）：
   头部 = 总额 +「充值」「提现」+ 关闭
   列表选项 = 勾选「隐藏 $1 以下资产」（默认勾选）

   - Holder dividends ready（◎）+ Claim all holder dividends
   - Creator fees（◆）+ Claim fees

```

## 3. 身份 hero 与 Portfolio 总览

### 3.1 身份与钱包卡片
- **版式**：身份 hero 为**卡片**（圆角 22、卡背景 + 细描边、内边距 18/20），上下两块：身份区在上，钱包区在下，中间以虚线上边线分隔。
- **身份区**：头像（登录用户有头像则显示图片，否则占位字符；访客态显示所查地址第 3 位大写字符）+ 地址 + **复制图标按钮**（28×28 方形图标，无文字；`title` / `aria-label` 均为「复制地址」）；行**右端**为「**Profile ›**」文字链接（英文，对应中文「个人主页」；`title` 为「个人主页」），跳转到个人内容主页 `profile-center.html`（`margin-left:auto` 靠右、12.5px / 700、hover 浅底 + 变黑、focus-visible 外描边；**访客态隐藏**，因为此时展示的是他人资产）。
- **地址**：**截断显示**（`0x1234…abcd`），完整地址写入 `title` 并作为复制按钮的内容；点击复制图标写剪贴板并 toast“地址已复制”。
- **钱包区**：`Balance` 小标签 + **Σ 计价资产美元估值（页面最大数字：桌面 40px / 窄屏 34px，等宽数字）** + `›`；右侧「充值」「提现」按钮。
  - 按钮形态：胶囊、高 38px、`inline-flex` + 线性图标（充值＝存入托盘箭头，提现＝取出托盘箭头，16px、stroke 1.9）+ 文案；主按钮（充值）黑底白字并带 1px 投影，悬停变亮并抬升阴影（`0 6px 18px`），按下 `scale(.97)`，键盘聚焦有 2px 外描边。图标纯装饰（`aria-hidden`），文案保留以保证可读。
  - 卡片与钱包面板**都不展示资产种数**（列表内容即所见）。
- **窄屏（≤560px）**：卡片内边距收为 16，钱包区改为纵向（金额在上、按钮整行等宽在下），金额字号降为 34px。

### 3.2 Portfolio
- `Portfolio` = Σ（持仓量 × 当前价 USD），字号 34px（页面最大数字为钱包卡的 Σ 计价资产估值 40px，两者口径独立、不混算）。
- 小字 pons 口径：`Across {N} open pons position(s)`（N=当前持仓币数）；持仓币数同时体现在 Positions 页签计数上。

### 3.3 PnL 走势卡
- 次级行（卡片右上、区间按钮下方，16px）：总 PnL = 未实现（持仓现价 − 成本）+ 已实现（`USER.realizedPnl`），带符号（`+`/`−`），后缀 `PnL · {1d|7d|30d}`；正绿负红。降低字号以避免与余额争主位。
- 范围按钮 1D / 7D / 30D 位于卡片右上：切换后曲线与 PnL 数值重绘。
- 图：确定性演示序列（按用户 id + 范围种子生成，向 PnL 方向漂移）；Y 轴 4 条网格 + 美元刻度（上界 = max(总市值, 总 PnL, 1)）；渐变面积 + 折线 + 末端点。
- 窗口 resize 时重绘。
- 语义声明：走势为**演示示意**，非实时行情。

### 3.4 钱包入口（桌面钱包条 / 移动端胶囊 + 钱包资产面板）
- **口径**：钱包 = **计价资产**（与 `coin-detail` 支付/收款下拉同一资产集合：`ETH / WETH / USDG / cbBTC` + 40 个股票代币）。
  展示 `Σ（余额 × 现价 USD）`；**不计入** `Portfolio`（后者仅 Σ 持仓市值），两者口径分开、互不混算。
- **入口（桌面与移动一致）**：身份与钱包卡片内的钱包区——点击 `Σ$` 金额区或 `›` 打开钱包资产面板；同卡片右侧的「充值」「提现」按钮默认作用于 ETH。
- **面板形态随断点**：桌面为居中面板，移动为**全屏底部抽屉**（不再有独立的移动端余额胶囊）。
- **权限**：未登录隐藏钱包条/胶囊（与 hero、Portfolio 一致）；访客态（`?address=0x…`）余额只读，任何操作先拦截（toast「访客视图不可操作」）。
- **刷新**：随 Portfolio 总览一起重渲染；面板内充值、提现、领取后即时刷新。

### 3.4.1 钱包资产面板
- 头部：`Balance` 标签 + `Σ$` 总额 + **「充值」「提现」两个操作按钮**（36px 胶囊、同款图标与交互态）+ 关闭按钮（不展示资产种数，列表内容即所见）。
  - 两个按钮默认作用于 **ETH**，打开后在弹层内可「切换资产」选任意计价资产（与 §3.5 / §3.6 同一套流程）。
- **列表选项**：列表上方一个勾选项「**隐藏 $1 以下资产**」，**默认勾选**；取消勾选后显示全部计价资产。
  - 判定口径：按美元估值过滤（`+ < $1` 视为灰尘余额，含余额为 0 的资产）；阈值常量 `AP_DUST_USD = 1`。
  - 头部**总额始终是完整钱包估值**（不因隐藏灰尘而减少）。
  - 当过滤后无任何资产时，空态提示「已隐藏 $1 以下的资产，取消勾选可查看全部」。
  - 演示数据按确定性规则固定给出 **8 个**灰尘余额（$0.18–$0.95，不含 ETH），便于走查该开关（默认勾选时列表 36 行、取消后 44 行）；真实环境应按实际余额判定。
- 列表：分组「加密资产」「股票」；**组内按 USD 市值降序**；每行**只读**展示资产图标、代码 + **资产全称**、余额、`≈$`。
  - 全称取引擎 `Launch.assetName(sym)`（44 种全覆盖：`Ether / Wrapped Ether / USD Global / Coinbase Wrapped BTC` + `NVIDIA / Tesla / Apple / SPDR Gold Shares / SPDR S&P 500 ETF / WhiteFiber …`），创建页配对下拉的 `pairName()` 也走同一来源，避免两处各写一份。
  - **不在行内放操作按钮**：行内三按钮 × 44 行会造成大量重复入口（弹层内已能切换资产），且挤压余额列；操作统一由头部按钮进入。
- 桌面为居中面板（宽 560、最高 80vh），移动为全屏抽屉（最高 88vh、可滚动、含安全区内边距）；窄屏时头部两个按钮整行等宽。
- 从面板内打开充值 / 提现弹层时，**面板保持在下层**，关闭弹层后回到列表并继续保持页面不滚动。
- 测试余额（水龙头）不在本面板提供，仍在币详情交易面板与创建页预买行的「水龙头 / 领取」处。
- 资产集合与分组由引擎 `Launch.quoteGroups()` 提供，避免与 `coin-detail` 下拉各写一份。

> 弹层约定：本页的充值 / 提现 / 钱包资产面板**自带静态隐藏态**（首屏 `opacity:0 + visibility:hidden`，显示类为 `.active`），不依赖运行期注入的样式；页面内受登录态控制的 hero / 钱包条 / Portfolio 也以 `display:none` 起始，由渲染逻辑决定是否显示 —— 避免进入或刷新页面时出现弹窗/骨架闪现。

### 3.5 充值（接收任意计价资产）
- 触发：钱包条「充值」（默认 ETH）、资产面板每行「充值」；未登录先走登录引导，访客态拦截（toast「访客视图不可操作」）。
- 顶部资产头显示当前资产（图标 + 代码 + 名称），点「切换资产」在弹层内换资产（分组选择器，与资产面板同一集合与排序）。
- 内容：二维码示意（静态占位图，标注「二维码示意（演示占位）」）+ 收款地址（钱包地址 `currentWallet.address()`，全量）+「复制地址」；
  **非原生资产额外显示该资产的合约地址 +「复制合约」**（转入 ERC-20 类资产必须核对合约）；原生 ETH 不显示合约行。
- 到账说明随资产变化：原生 ETH → 仅支持 Robinhood Chain 上的 ETH；其它资产 → 仅支持该合约地址对应的资产，转入其它网络或其它代币无法找回。
- 关闭：✕ / 遮罩 /「关闭」；不含法币通道；二维码为静态占位、不随地址与资产变化。

### 3.6 提现（转到外部地址，任意计价资产）
- 触发：钱包条「提现」（默认 ETH）、资产面板每行「提现」；未登录或访客态同上拦截。
- 顶部资产头同充值（可「切换资产」）；字段：目标地址、金额（当前资产）、`MAX`；
  实时摘要 = 该资产可用余额 / 网络费（预估） / 到账数量 / **ETH 余额（付 gas）**。
- 校验（行内红字 + 主按钮禁用）：
  - 地址须 `0x` + 40 位十六进制；禁止零地址与当前钱包地址；
  - **网络费（gas）固定以 ETH 计价**：ETH 余额必须 ≥ `WD_GAS_RESERVE = 0.002 ETH`，否则拦截并提示「ETH 余额不足，需预留网络费约 0.002 ETH」；
  - 金额 > 0；提现 ETH 时金额 ≤ ETH 余额 − 预留值，提现其它资产时金额 ≤ 该资产余额（`MAX`：ETH 扣预留值，其它资产取全部余额，保留 6 位小数）。
- 提交后**签名确认**（内嵌钱包，含拒绝分支）：
  - 弹窗展示转出资产与金额、目标地址（全量）与网络费预估（以 ETH 支付），底部注明「由 Privy 提供（模拟）」；
  - 「拒绝」→ 关闭并 toast「已取消提现」，保持填写态且**不扣减**；
  - 「签名并提交」→ 按钮依次显示「签名中…」「上链中…」，成功后按金额扣减**该资产**余额（ETH 余额仅在提现 ETH 时变化）、持久化、刷新钱包条 / 资产面板 / Portfolio 总览并 toast「提现已提交」。
- 提现**不计入** Activity 页签流水（该页签为买卖成交流水口径），也不改变 Portfolio 口径。

## 4. 领取横幅（位于 Portfolio 上方）

| 横幅 | 出现条件（本人） | 文案 | 行为 |
|---|---|---|---|
| Holder dividends | 持有币中至少一个 `ready` 且金额 > 0 | `{合计} ready across {N} coin(s)` | Claim all：逐个入账（按该币配对资产 credit），并标记已领；toast 汇总 |
| Creator fees | 自己发射币中有 `claimable > 0` | `{合计} claimable across {N} launch(es)` | Claim fees：循环 `Launch.claim(id)`，toast 汇总 |

- 判定口径与币详情页一致：
  - 持有人分红：发行配置 `shareToHolders` 且未领（`sf_div_claimed` 记录 id）→ `ready`；另有演示态覆盖（见 §9）。
  - Creator fees：`USER.claimable[id] > 0` → ready；`USER.claimed[id] > 0` → claimed；否则 Open。
- 已领取 / 无可领时横幅不出现。
- 视觉与间距：白底 + 细描边 + 黑色圆形图标 + 黑色主按钮（不用黄色告警底）；横幅 `margin: 12px 0 14px`，与相邻块外边距按常规合并 —— 两条同时出现时彼此 14px，最后一条与下方 `Portfolio` 卡之间 14px；两条都隐藏时不占位、不留空档。

## 6. Positions（Open positions）

### 6.1 行字段
| 列 | 取值 |
|---|---|
| 币 | 封面/占位 + 名称 + `$代号 · {time ago} · {N} trades`（N=自上次完整退出以来的买+卖次数） |
| Entry mcap | 建仓均价对应市值 = 当前市值 ×（均价 ÷ 现价） |
| Current mcap | 当前市值 |
| Value | 持仓量 × 现价（USD） |
| PnL | ▲/▼ + 带符号金额 + 百分比（成本 > 0 时），红绿着色 |

- 行整体点击 → 币详情页；行内分享按钮阻止冒泡。
- 表头带「分红演示」切换按钮（见 §9）；该按钮仅在 `?debug=1` 或 `localStorage.sf_debug = '1'` 时出现。

### 6.2 分享卡（OPEN POSITION）
- 弹层展示 HTML 分享卡：`OPEN POSITION · story.fun` + 币图/名称/代号 + Entry mcap / Current mcap / Value / PnL 四格 + 页脚日期。
- 「复制图片 / 下载图片」为**演示占位**：toast“演示占位（不生成文件）”，不真实产出图片。
- 关闭：✕ 或点击遮罩。

### 6.3 空态
- “还没有持仓 / 发现一个叙事，从第一笔开始” + 去市场按钮。

## 7. History（Closed positions）

- 数据源：完全退出记录 `USER.closed`（记录 `coinId / name / symbol / entryMcapUsd / investedUsd / realizedPnlUsd / totalPnlUsd / totalPnlPct / buys / sells / exitAt`）。
- 行字段：币（含 `{time ago} · {N} trades`）、`Entry mcap`、`Realized`（红绿）、`Invested`、`PnL`（▲/▼ + 金额 + %）。
- 分享卡：`CLOSED POSITION`，字段同上（Realized / Invested / PnL）。
- 空态：No closed positions yet.（完全卖出后出现已实现 PnL）。

## 8. Activity

- 数据源：`USER.tx`（倒序，至多显示 40 条）；行点击回币详情。
- 行内容：`Bought/Sold {数量缩写} ${代号}`（大写行）+ `{币名} · ${净额或总额 USD}`（小字）+ 右侧时间 `{timeAgo} ago`。
- 数量缩写（pons 口径，小写 k）：`1.23k / 1.20M / 1.10B / 2 位小数 / <1 用 3 位有效数字`。
- 空态：No trades found in the recent lookback window.（含引导按钮）。

## 9. Launches（自己发射的币）

- 数据源：`USER.created`（发行流程落库的币 id 列表）。
- 行：封面 + 名称 + `$代号 · Graduated/curve · 市值`，右侧状态：
  | 状态 | 展示 |
  |---|---|
  | Ready | `Ready · {金额 USD}`（有 claimable） |
  | Claimed | `Claimed · {金额 USD}` |
  | 其他 | `Open` |
- 表头带「领取状态演示」按钮（见下）；同样仅在 `?debug=1` 或 `localStorage.sf_debug = '1'` 时出现。
- 空态：No launches yet. + Launch a token。
- 行点击 → 币详情页。

### 9.1 演示开关（原型专用，默认隐藏）
- 仅在 `?debug=1` / `sf_debug=1` 时，页签内右上角出现循环按钮，切换 localStorage 状态，即时重渲染与横幅同步：
  - 持有人分红演示（Positions 表头，`sf_div_demo`）：自动（按配置与已领记录判定）/ 待领取 ready / 已领取 claimed / 无 none。
  - Creator fees 演示（Launches 表头，`sf_fee_demo`）：自动 / 待领取 ready / 已领取 claimed / 无收益 open。
- 演示态下点领取按钮：不真实入账，仅 toast“演示：已领取…”并把状态切到已领取（`sf_div_demo`/`sf_fee_demo`），便于走查 UI 各状态。

## 10. 数据与状态口径（引擎）

- 数据引擎：`launch-coin.js`（`window.Launch`），账户状态存 `Launch.USER`：
  - `holdings{coinId:{amount, avgUsd}}`、`closed[]`、`tx[]`、`created[]`、`realizedPnl`、`claimable/claimed{coinId}`。
- 币数据按 id 取 `Launch.coinById`；价格 `coin.priceUsd`；市值 `coin.marketCap`。
- 分红/费用领取均以币的**配对资产**入账（`Launch.credit(pair, qtyOfUsd(usd))`），与币详情页一致。
- localStorage 演示键：`sf_div_claimed`（已领分红 id）、`sf_div_demo`、`sf_fee_demo`；地址角色演示键沿用全局（auth / `sf_demo_role`）。
- 页面就绪走 `window.onLaunchShellReady`（切换范围、复制、页签、两个 Claim、resize、auth-ready、首渲）。

## 11. 异常与边界

| 场景 | 行为 |
|---|---|
| 未登录打开 | 显示登录引导卡，其余区块隐藏 |
| 访客打开并点领取 | 横幅不出现；即使触发也 toast“访客视图不可领取” |
| 无可领分红/费用点 Claim | toast“暂无可领取…” |
| 持仓成本为 0 | PnL % 显示 0 基线，金额照常 |
| 分享按钮（复制/下载图片） | 演示占位 toast，不生成文件 |
| resize | PnL 图重绘 |
| 空持仓 / 无流水 / 无发射 | 各页签空态与引导按钮 |
