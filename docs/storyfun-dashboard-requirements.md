# Storyfun 数据看板 · 产品需求说明（真实后台口径）

> 依据已确认的数据看板简化方案整理（原方案文档已并入本文件，不再单独维护）。
> 本文按**真实后台系统**书写：描述功能、指标口径与交付约束，不含原型/演示语义；
> 各指标统一以“默认口径”执行；如需调整，按产品确认的单点变更处理。

---

## 1. 范围与页面

系统提供 4 个看板页面：

| 页面 | 定位 |
|---|---|
| 用户概览 | 用户规模、创作者/发射者渗透、活跃、人均在线/登录与 DAU·WAU·MAU 趋势 |
| 用户来源 | 注册用户的国别 / 地区分布 |
| 功能概览 | 以“人”为单位的功能参与率与下钻明细 |
| 代币概览 | 发射与交易的 24h / All-time 指标与趋势 |

> 内容单元（短剧单集/短视频）的播放、完播、热度、留言与协议收入/排行榜等指标本期不在范围内。

---

## 2. 全局口径

| 项 | 约定 |
|---|---|
| 时间基准 | 全站统一 UTC；业务日 = UTC 自然日（00:00–24:00） |
| 24h 窗口 | 最近一个**完整 UTC 日**（昨日 00:00–24:00 UTC） |
| 周 / 月 | UTC 自然周 / 自然月 |
| 活跃定义 | 当日发生任一被追踪行为（登录 / 观看 / 互动 / 交易 / 发布 / 发射），默认口径 |
| 去重口径 | 均按 user id 去重；“创作者 / 发射者 / 参与者”= 发生过该行为的独立用户数 |
| 人均口径 | 人均在线时长 / 人均登录次数 = 当日总量 ÷ 当日活跃用户（默认口径） |
| 数据更新 | 按 UTC 日批量入仓；页面顶部展示“最近一次数据截至”时间 |
| 数值格式 | 数量 K/M/B/T；金额 `$`；比率保留 1–2 位小数 |

## 3. 用户概览

| 指标 | 口径 | 粒度 | 默认窗口 |
|---|---|---|---|
| 注册用户数 | 注册事件累计，按 uid 去重 | 累计 / 可切窗口 | 全量 |
| 创作者数量 / 占比 | 发布过内容单元的用户数 ÷ 注册用户 | 累计 / 可切窗口 | 全量 |
| 发射者数量 / 占比 | 发射过代币的用户数 ÷ 注册用户 | 累计 / 可切窗口 | 全量 |
| DAU | 当日活跃用户（§2） | 日 | 近 30 日 |
| WAU | 自然周去重活跃用户 | 周 | 近 12 周 |
| MAU | 自然月去重活跃用户 | 月 | 近 12 月 |
| 人均在线时长 | 当日总在线时长 ÷ 当日活跃用户 | 日 | 近 30 日 |
| 人均登录次数 | 当日总登录次数 ÷ 当日活跃用户 | 日 | 近 30 日 |
要求：
- 活跃趋势图支持 **DAU / WAU / MAU 切换**（日 / 周 / 月粒度），默认 DAU 近 30 日；
- 支持自定义时间区间。

## 4. 用户来源

| 维度 | 统计 |
|---|---|
| 国家 | 注册用户数量、占比（÷注册用户） |
| 地区 | 注册用户数量、占比；地区由“国家 → 地区”映射表归并（北美 / 欧洲 / 亚洲 / 中东 / 拉美 / 非洲 / 大洋洲） |

> 国家归属口径：注册时 IP 的 GeoIP；地区由“国家 → 地区”映射表归并并可后台维护。钱包链上归属 / onboard 渠道留作单点变更项。

---

## 5. 功能概览

| 功能 | 参与口径 | 分母 |
|---|---|---|
| 注册 | 完成注册 | **PV（注册入口访问量）** |
| 观看 | 观看任一内容单元 ≥1 次 | 注册用户 |
| 举报 | 举报内容 ≥1 次 | 观看用户 |
| 不感兴趣 | 标记不感兴趣 ≥1 次 | 观看用户 |
| 发布内容 | 发布 ≥1 个内容单元 | 注册用户 |
| 发射代币 | 发射 ≥1 个币 | 注册用户 |
| 买入代币 | 买入成交 ≥1 笔 | 注册用户 |
| 卖出代币 | 卖出成交 ≥1 笔 | 注册用户 |

说明：
- 参与率 = 该功能参与独立用户数 ÷ 分母；注册的参与率 = 完成注册用户数 ÷ 注册入口 PV（如需按人统计可另给 UV 口径）；其余功能分母为产品口径。
- 每项功能支持**下钻明细**：参与用户列表（uid / 钱包、参与次数、首次参与时间、最后参与时间）。
- 明细列表要求：时间区间过滤、多字段排序、服务端分页、CSV 导出；**不设业务条数上限**。
- 总览与明细必须同源同口径。

## 6. 代币概览

| 指标 | 口径 | 窗口 |
|---|---|---|
| 发射代币数量 | 新发射币总数 | 24h / All-time |
| 发射者数量（去重） | Unique token devs = 发币用户去重 | 24h / All-time |
| 交易量 $ | 链上成交额合计（curve 阶段 + 池内） | 24h / All-time |
| 近 30 日发射趋势 | 日序列（柱） | 近 30 日 |
| 近 30 日成交量趋势 | 日序列 | 近 30 日 |

## 7. 验收清单

- [ ] 用户概览各指标与口径一致；活跃趋势支持 DAU/WAU/MAU 切换与时间区间
- [ ] 创作者 / 发射者按 uid 去重，占比分母 = 注册用户
- [ ] 用户来源：国家 / 地区数量与占比正确，映射表可维护
- [ ] 功能概览 8 项参与人数 / 参与率正确；下钻明细含用户、次数、首末参与时间
- [ ] 明细列表支持时间过滤、排序、服务端分页与 CSV 导出（不设条数上限）
- [ ] 代币概览：24h / All-time 发射、Unique devs、交易量；近 30 日发射数量与成交量两图
- [ ] 页面顶部展示“最近一次数据截至”时间，聚合口径与明细一致

---

## 8. 数据依赖建议（事件 / 聚合层）

- 事件层：注册、登录、观看、互动（举报 / 不感兴趣）、发布内容、发射代币、买入成交、卖出成交（均含时间戳与 user id；交易类含金额）。
- 用户属性表：uid、钱包地址、注册时间、注册 IP（→国家 / 地区）。
- 币表：币 id、发射者 uid、发射时间、pair、状态（curve / 已毕业）、市值与成交量日快照。
