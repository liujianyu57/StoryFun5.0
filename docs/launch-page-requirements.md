## 1. 页面定位与用户故事

- **定位**：创作者把叙事/作品发射成链上代币的创建入口；创建后进入发行曲线，募满即毕业上池。
- **用户故事**
  - 作为创作者，我可以关联一部短剧/AI 叙事作为故事来源，并独立上传一张**必填的币图**作为代币门面。
  - 作为创作者，我可以配置费用分配、创作者税与狙击豁免名单，并实时预览费用摘要。
  - 作为评审/运营，我希望创建前的每个参数含义与边界清晰，关键风险（狙击、税率、毕业、费用）被明确提示。

## 2. 主流程与信息架构

```
进入页面
 ├─ ① 基础信息（名称 / 代号 / 可选一句话介绍）
 ├─ ② 关联叙事（选填）→ 币图默认带入其封面
 ├─ ②b 币图（必填）→ 可上传/更换（≤5MB，常见图 + GIF）
 ├─ ③ 社交资料（选填）：X handle / Telegram handle
 ├─ ④ 发行参数
 │    ├─ 配对资产（ETH + 股票代币，计价/结算货币）
 │    ├─ 开发者预买（选填）
 │    └─ 高级设置
 │         ├─ 费用分配（分给持有者 / 归我指定钱包）
 │         ├─ 创作者税（0–10%）
 │         └─ 狙击税豁免名单（默认 0，上限 32）
 ├─ ⑤ 实时摘要：发行费（ETH）+ gas 提示、路由/税率、狙击窗口、毕业阈值
 └─ 创建：点“创建并上架”→ **Review launch 确认弹窗**（pons：🚀 Launch {SYM} + 两列参数行 +
     Confirm / Cancel，参数为提交瞬间快照）→ Confirm → 发射成功弹窗
     （pons 形态：✓ + 币图 + `{SYM} launched` + 名称 + 费率去向 + 地址；
     按钮 Trade token / Transaction；链接 Launch another / Back to explore）
```

## 3. 字段字典

### 3.1 基础信息

| 字段 | 含义 | 必填 | 输入/校验 | 默认 | 联动/说明 |
|---|---|---|---|---|---|
| 名称 Name | 代币对外名称 | 是 | 1–60 字符（Unicode 码点计数，中文/emoji 各计 1）；先 trim | 空 | **允许重复**；不参与唯一性 |
| 代号 Symbol | 交易代号 | 是 | 2–20 位大写 A–Z / 0–9（输入小写自动转大写） | 空 | **允许重复**；同名同代号的首发币带 **OG 标识**（判定忽略大小写/空格） |
| 一句话介绍 Tagline | 简述项目 | 否 | ≤256 字符（码点计数） | 空 | 详情页展示 |

### 3.2a 关联叙事（选填）

| 控件 | 含义 | 规则 |
|---|---|---|
| 关联叙事 | 绑定已有短剧/AI 叙事，作为该币的故事来源 | 独立选填；不选也可创建 |
| 封面带入 | 选中叙事后，币图默认带入其封面/视频封面 | 为默认值，用户可上传覆盖 |
| 叙事视频 | 若叙事带视频，一并作为币的叙事视频 | 与币图互不影响 |

### 3.2b 币图（必填）

| 项 | 含义/规则 |
|---|---|
| 币图 | 代币主视觉（列表/详情/分享卡封面）—— **必填** |
| 大小/格式 | ≤5MB；支持常见图片格式与 GIF 动图（GIF 预览播放；详情/分享取静态首帧）；不强制宽高比 |
| 默认来源 | 关联叙事后自动带入叙事封面；未上传即以此满足“必填” |
| 上传状态 | 未选 → 上传中（IPFS）→ 已就绪；预览卡同步 |
| 重传/失败 | 允许重传覆盖并同步替换引用；失败保留旧图 |
| 校验 | 未关联叙事且未上传图 → 阻止创建并提示 |

### 3.3 社交资料（选填）

| 字段 | 含义 | 校验 |
|---|---|---|
| X handle | X 账号名（**不带 @、不含域名**） | ≤15 位字母/数字 |
| Telegram handle | 社群账号名（同上语义） | ≤32 位字母/数字 |

> 社交为空不影响上架，仅影响详情社区入口展示。平台内不校验 handle 冲突（与名称/代号允许重复保持一致）。

### 3.4 配对资产（计价资产）

- 含义：本币的计价/结算货币；发行曲线价格、费用、毕业阈值都以它计。
- 可选范围：**ETH + 股票代币**（WETH/USDG/cbBTC 等只出现在交易页“支付资产”，不可作计价）。
- 选中后联动：
  1. 摘要（配对资产/发行费/发射窗口）同步；
  2. 开发者预买行币种、可用余额、Max 跟随切换，**切换即清空已填预买量**（防单位错配）。

### 3.5 开发者预买（选填，团队首笔建仓）

| 概念 | 说明 |
|---|---|
| 数量（输入单位） | 投入的**配对资产金额**；所得币数 = 投入 ÷ 发行价，UI 同步展示预计币数 |
| 会计关系 | **计入曲线池与毕业进度**（等同于发射交易的一笔买入） |
| 持仓 | 预买计入创建者持仓；**占比 >20%** 触发“发行者持仓警示”徽标 |
| 可用余额 / Max | 展示该配对资产可用额；Max 一键填满 |
| 水龙头 | 测试/演示补额入口；生产环境不出现 |
| 校验 | 数量 ≥ 0 且 ≤ 余额，否则阻止并提示 |

### 3.6 高级设置

#### (a) 费用分配（单选）
| 选项 | 语义 | 界面联动 |
|---|---|---|
| 分给持有者（Holder fee sharing） | 创作者费归持有者，经费分配器分发 | 隐藏“收款钱包”输入 |
| 归我（指定钱包） | 创作者费打给指定收款地址 | 显示“收款钱包”输入 |

> 默认=归我；创建后仍可切换（持有人 ↔ 钱包）。

#### (b) 收款钱包
- 默认：**创建时当前连接钱包**（创建即写死为收款人）
- 创建后可在币详情 Transfer 更改，只影响未来费用；历史已累积待领不受影响；变更即时生效（无冷却/时间锁），详情展示最近变更时间
- 校验：合法链上地址；为空则使用连接钱包

#### (c) 创作者税 Creator tax
- 含义：交易费之上按成交额加收的额外费率，归创建者或按 (a) 归持有者
- 输入：0–10%，支持小数；失焦/回车钳制，非法输入回退提示
- 变更：**创建后不可提高、不可降低或关闭**（参数冻结）；如需调整费用政策，用费用路由切换表达

#### (d) 狙击税豁免名单
- 背景：发行首秒买入触发 99% 狙击税，3 秒内衰减至 0（从发射交易上链时刻起算、线性衰减）—— 拦截抢跑机器人
- 含义：声明不受狙击惩罚的钱包（**可包含自己**；默认 0 个）
- 规则：上限 32；重复去重；非法地址拒绝；满 32 禁用；**创建后不可修改（链上写死）**
- 豁免仅免狙击税，**平台基础交易费照收**；名单数量在详情公开，地址链上可查
- 常驻提示：说明狙击窗口并要求声明团队钱包

### 3.7 按钮文案与状态

| 状态 | 文案 |
|---|---|
| 默认可提交 | 创建并上架 |
| 进行中（等钱包/签名/上链） | 创建中…（禁用，防重复提交） |
| 签名被拒 / 网络失败 | 恢复可提交并提示错误，保留已填内容 |
| 成功后 | 发射成功弹窗（居中卡片）：✓ + 币图 + `{SYM} launched` + 名称 + 费率去向 + 地址；Trade token → 币详情；Transaction → 演示占位；Launch another → 重新发射；Back to explore → 市场页 |

## 4. 摘要区（实时预估）

- 内容：`{配对} 配对 · 应付发行费 {ETH}`、费用路由/税率、狙击窗口、预计毕业阈值
- **ETH 提示**：发行费与 gas 均以 ETH 结算 —— 当计价资产非 ETH 时，仍提示需持有 ETH
- 任一发行参数变化（配对/预买/税/路由）→ 摘要即时刷新

---

## 5. 业务规则

1. 创建即上架：立即进入发行曲线，无人工审核期（合规另披露）
2. 毕业：曲线募满该配对资产阈值后自动上池，流动性永久锁定
3. 费结构：交易基础费率 + 可选创作者税；按费用分配路由（持有者 / 钱包）
4. 狙击税：全局常量（首秒 99%、3s 衰减至 0），创建者不可配置；豁免名单内地址不受惩罚
5. 命名：名称与代号允许重复；同名同代号首发带 OG 标识
6. 开发者预买计入曲线/毕业，记入团队持仓
7. 收款人创建时写死为连接钱包，创建后可 Transfer 更改（仅影响未来）
8. 允许未连接钱包浏览/填表；创建时需连接正确网络钱包

## 6. 创建后可变性对照表

| 参数 | 创建后可否变更 |
|---|---|
| 供应量 / 定价曲线 / 计价资产 | 不可变 |
| 狙击税豁免名单 | 不可变 |
| 创作者税 | 不可提高，亦不可降低或关闭（参数冻结） |
| 费用分配路由（持有人 ↔ 钱包） | 可变（详情页切换） |
| 收款地址 Fee recipient | 可变（Transfer，仅影响未来） |

## 7. 异常与边界

| 场景 | 预期行为 |
|---|---|
| 名称为空 / 超 60 | 行内提示，阻止 |
| 代号非法 / 超 20 | 行内提示，阻止 |
| 介绍 >256 | 计数超限提示 |
| 未关联叙事且未上传币图 | 阻止并提示上传币图 |
| 币图超 5MB / 格式不支持 | 上传即拒绝并提示 |
| X/TG handle 超长或含非法字符 | 行内校验提示 |
| 预买 <0 或超余额 | 阻止并提示可用余额/Max |
| 税率非法（>10 / 负 / 非数） | 失焦钳制；无法提交 |
| 豁免地址非法 / 重复 / 满 32 | 拒绝添加 / 去重 / 禁用 |
| 收款钱包非法 | 校验提示 |
| 切换配对资产 | 清空预买、重置余额/阈值，防错配 |
| **钱包未连接** | 引导连接后再创建 |
| **网络错误 / 切换失败** | 提示并引导重试 |
| **gas 不足** | 明确报错，不进入签名 |
| **用户拒绝签名** | 恢复表单、不产生半成品 |
| 创建中重复点击 | 按钮禁用防重 |
| 成功 | 发射成功弹窗：见 §3.7「成功后」 |
