> 按真实产品语义撰写；不含演示数值。
> 页面：`coin-detail.html`（币详情 + 交易）
> 阅读建议：本页结构以 **「毕业状态（未毕业/已毕业）」×「身份视角（游客 / 路人 / 持有人 / 创建者）」** 为主轴，请对照第 0 节场景矩阵阅读各章节。

## 1. 页面定位与用户故事

- **定位**：单币详情 + 交易页：看状态、看数据、做买卖、管理费（创建者）、领分红（持有人）。
- **用户故事**
  - 作为用户，我想一眼分清这是“发行曲线中”还是“已上池”，并能按我的身份完成对应操作。
  - 作为持有人，我想知道我的持仓/收益并领取持有人分红。
  - 作为创建者，我想查看并收取创作者费、变更收款人、调整费用路由。
  - 作为访客（未登录/路人），我应能只读浏览全部信息，操作时被引导连接。

### 2.1 移动端（≤820px）交易入口（底部弹层）

- 手机宽度下页面底部（站点底导上方）常驻一条通栏主按钮「交易 ⇄」；点按将**交易卡本身**（身份行 + curve 进度 + 买卖表单 + 滑点/明细）以**底部弹层**形态上滑打开——复用同一份 DOM，不复制表单/数据。
- 弹层构成：半透明遮罩 + 顶部把手 /「交易」标题 / 关闭 ✕；打开时页面锁滚动，弹层内容超高时可内部滚动；打开瞬间刷新报价与余额。
- 关闭方式：✕、点遮罩、Esc、或视口变宽到桌面断点（自动复位）。
- **顶部吸顶币信息头**：≤820px 时页面顶部为吸顶头（毛玻璃、计入安全区）：币图（纯展示）+ 名称 + $代号；创作者地址不在此重复（About 卡提供完整地址 + 复制）。769–820px 时吸顶头下移 56px 避开固定站点顶栏。
- >820px（含平板 821–1020 单列）与桌面：吸顶头与按钮/遮罩/把手隐藏，交易卡保持原有页内卡片形态，既有功能无回归。

## 3. 顶部与币身份（恒定）

- 顶部仅保留「← 市场」返回（无独立头部身份区、无标签行、无关注/分享操作钮）。
- 币身份作为**交易卡卡头身份行**展示（见 §2 第 5 项）：币图纯展示 + 名称/$代号 + `Paired {pair}`；未毕业时 `Bonding curve` 状态随下方 curve 毕业进度块呈现，已毕业时身份行显示 `Uniswap v4`。
- 合约地址（可复制）与 Creator（创建者地址，可复制）均在 About 卡内：Creator 为胶囊条；Token Contract 为右栏小卡；外链按钮统一放底部链接条。

## 5. 交易（按毕业状态与身份）

### 5.1 通用规则
- 未登录：查看可读，点击“买入/卖出/下单/领取”等触发连接引导。
- 金额侧单位：买入=支付资产数量；卖出=币数量；支付资产可切换（ETH/WETH/USDG/cbBTC/股票，自动折算），**计价与结算始终按本币配对资产**。
- 面板双行标签恒定：输入侧 `Sell`、输出侧 `Buy`（pons 口径）；面板中部对调按钮在买/卖间切换（买入=付支付资产得币；卖出=付币得 {pair}）。输出金额**左对齐**，提交按钮**通栏宽**。
- 滑点：默认 1%（面板不展示调整/明细行；Review 中展示对应滑点行）。
- 所有成交先进入 **Review 弹窗**，买/卖两套版式分别对齐 pons：
  - **买入 Review buy**：字段 = You send / Minimum received / Maximum slippage / Network: Robinhood Chain (4663) / Route: 0x aggregator；主按钮 `Buy {SYM}` + 下方 `Cancel` 链接；
  - **卖出 Review sell**：字段 = You send / You receive / Market / Max slippage；按钮 `Confirm sell`（绿）+ `Cancel` 并排。
- 成交成功后弹出**结果卡**（pons：`{资产} received`）：Complete + 数量大字 + Amount / Value 行；`View transaction`（原型演示占位）、`Swap again`（关闭返回继续交易）；买币触发毕业时改走毕业庆祝动效，不弹结果卡。

### 5.2 按状态
| 场景 | 可用交易形态 |
|---|---|
| 未毕业 | Market（曲线买卖：随池额推进价格、毕业即停） |
| 已毕业 | Market（池内买卖） |

### 5.3 关于 Limit / Orders / Heatmap
- 按 pons **v2** 语义：发行曲线阶段与毕业后**均不提供**限价单、挂单列表与买卖热力图（这些属于 v1/V3 池页能力）；
- 本页统一为「Market 即时成交 + Review」单一形态。

### 5.4 校验与异常（交易）
- 金额为空/非法、余额不足（支付资产 / 持仓）、目标未填、滑点/价格影响超限 → 行内或 toast 阻止。
- 成交后刷新 curve 毕业进度/四格统计/持仓/记录。

## 6. 费用区（身份 × 路由，重点分层）

费用区只在**未毕业**展示（已毕业费用已交付：发行者到 Profile/账户领取；持有人到 Profile 领取）。

### 6.1 前置：费用路由
- 路由 = 本币发行配置：`wallet`（归指定钱包）或 `holders`（归持有者）。
- 创建后可切换（见 6.4）；切换只影响之后产生的费用。

### 6.2 路由=wallet（归指定钱包）
| 视角 | 展示 |
|---|---|
| 游客/路人（只读） | Claimable 只读大数字 + 说明（Payable to …，无操作按钮） |
| 持有人（非创建者） | 同上（持有人不领 creator 费） |
| 创建者 | **Fee recipient**（脱敏地址 + Transfer）；**Collect curve fees**（把曲线 pending 并入可领余额，按钮在无可收时消失）；**Claim {pair}**（按本币配对资产领取，可领为 0 时提示“先 Collect”） |

### 6.3 路由=holders（归持有者）
| 视角 | 展示 |
|---|---|
| 游客/路人 | 卡1“no creator claim”；卡2 分红数据（Paid to holders / In the pot）只读 |
| 持有人 | 卡2 显示本人份额并出现 **Claim dividends**（领取按本币配对资产入账，领完消失） |
| 创建者 | 同上；额外拥有“路由切换”控件（见 6.4），不领取持有人分红（除非本人也持有） |

### 6.4 创建者路由控制（两张卡的联动）
- Holder fee sharing 卡内提供 `Share fees with holders` ↔ `Route to wallet {addr}` 切换；
- 切到 holders：Creator 卡变 “routing to holders, no creator claim”；
- 切回 wallet：Creator 卡恢复收款人 + Collect + Claim{pair}；
- 切换仅影响之后产生的新费用。

### 6.5 Fee recipient（创建者）
- 默认 = 创建时连接钱包（写死）；
- 可在详情 Transfer 改为新地址：仅影响未来费用；变更即时生效（无冷却），展示最近变更时间；
- 校验：合法链上地址。

## 8. About 与叙事

- 页面顺序：About 卡 → 叙事（独立卡）→ 费用卡（未毕业）→ 交易×K线网格 → 成交记录/持有者页签。
- About 版式：毕业/未毕业**同一套**（不随毕业切换燃烧/费用回馈卡）。分区排版 = 左（描述 + Creator 胶囊：mono 地址可复制 + creator tax）｜ 右栏（Supply·Fixed at launch / Paired / Contract 三张轻卡，Contract 等宽可复制）｜ 底部链接条（Explorer 原型外链演示 + Twitter/Telegram 按创建 handle 条件显示，跳 x.com / t.me）。≤860px 单列、链接条左对齐。
- 叙事：独立**行卡**（非大封面）置于 About 与 Creator fees 之间——▶ 图标 + “这个币的故事” + 一句话简介（单行省略），点击整卡进入浮层（storyModal）全屏播放；About 与叙事均未登录可读。

## 9. 异常与边界（追加于各模块之上）

| 场景 | 行为 |
|---|---|
| 未登录执行任何交易/领取 | 弹连接引导，操作不执行 |
| 非创建者看 creator 费卡 | 无 Collect/Claim/Transfer 按钮（只读） |
| 创建者当前无可收/可领 | 对应按钮消失并给状态说明（Collected / Collect first / —） |
| 非持有人看分红 | 无 Claim dividends（数据可见） |
| 已毕业访问 | 不展示曲线费用区（费用已交付），改为可在 Profile 领取 |
| 交易 Review 阶段返回/关闭 | 不产生成交 |
| 网络/签名被拒 | 恢复表单、保留输入 |
| 视频加载失败 | 回退封面，不破版 |
